strictgen playground

One JSON Schema in, strict Rust, Go and TypeScript out. Everything runs in this page: the generator, and the generated TypeScript decoders. Nothing you type is sent anywhere. The link holds the page's state in its fragment, after the #, which browsers don't send to the server.

Decode a payload

The decoders are the generated TypeScript, compiled in this page. The conformance suite holds the Rust and Go decoders to the same results: the same accept or reject, the same error and the same unknown keys.

Rust and Go are shown as generated, before formatting. strictgen generate runs rustfmt and gofmt on them by default, which changes their layout. TypeScript and the LLM schemas are written as shown.
